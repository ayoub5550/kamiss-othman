# قميص عثمان
### موسوعة الذرائع: كيف بُنيت سرديات الحروب في الشرق الأوسط وشمال إفريقيا (1900–2026)

كُتب بمساعدة الذكاء الاصطناعي (Claude عبر Viktor) — مشروع ومبادرة: **أيوب** (طالب، الجزائر).

> "قميص عثمان" — كما اتخذ معاوية بن أبي سفيان قميص الخليفة عثمان بن عفان الملطخ بالدماء ذريعةً لبناء دولته وشرعنة حربه، اتُّخذت عبر التاريخ الحديث ذرائع مشابهة — حادثة، وثيقة، "تهديد"، أو مظلمة — لإشعال حروب كانت مقرَّرة أصلاً لأسباب أخرى. هذا الكتاب يوثّق الفارق بين الذريعة المعلنة وما حدث فعلاً خلف الكواليس، بالوثائق لا بالانطباع. **لذلك يحمل كل فصل عنوان الذريعة نفسها، لا مجرد اسم الحدث.**

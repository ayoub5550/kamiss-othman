# قميص عثمان
### موسوعة الذرائع: كيف بُنيت سرديات الحروب في الشرق الأوسط وشمال إفريقيا (1900–2026)

كُتب بمساعدة الذكاء الاصطناعي (Claude عبر Viktor) — مشروع ومبادرة: **أيوب** (طالب، الجزائر).

> "قميص عثمان" — كما اتخذ معاوية بن أبي سفيان قميص الخليفة عثمان بن عفان الملطخ بالدماء ذريعةً لبناء دولته وشرعنة حربه، اتُّخذت عبر التاريخ الحديث ذرائع مشابهة — حادثة، وثيقة، "تهديد"، أو مظلمة — لإشعال حروب كانت مقرَّرة أصلاً لأسباب أخرى. هذا الكتاب يوثّق الفارق بين الذريعة المعلنة وما حدث فعلاً خلف الكواليس، بالوثائق لا بالانطباع، وبأسلوب سردي تحقيقي يشدّ القارئ كما يشدّه تحقيق بوليسي — لأن كل فصل هنا هو فعلاً لغز حقيقي له وثائقه وشهوده وضحاياه.

## طريقة العمل

## الحالة الحالية
**اكتملت جميع الفصول السبعة عشر (00 إلى 17)** — من سايكس-بيكو ووعد بلفور (1915) إلى حرب إيران الأخيرة المستمرة (2025–2026)، كل فصل موثّق بمصادر أولية/رسمية أو تحقيقات صحفية استقصائية معتمدة، مع قسم "العمل الاستخباراتي والكواليس" الإلزامي في كل فصل. **صدرت في 2026-09-15 نسخة سردية كاملة منقّحة**: عناوين مبتكرة قائمة على أصدم تفصيلة في كل قصة (بدل الصيغة الجافة "ذريعة كذا")، فقرة استهلالية "خطّافة" (hook) في بداية كل فصل، **وإعادة صياغة كاملة لجسم جميع الفصول السبعة عشر** (لا العناوين فقط) بأسلوب تحقيقي/استقصائي متصل يشدّ القارئ بدل النقاط الجافة المتفرقة — راجع `AGENT.md` لدليل الأسلوب الكامل. ملاحظة: فصلا غزة (16) وإيران (17) يوثّقان نزاعين لا يزالان مفتوحين وقت الكتابة ويحتاجان تحديثاً دورياً. الخطوات التالية الممكنة: (أ) توسيع القائمة بالأحداث الإضافية المذكورة أعلاه، (ب) مراجعة تحريرية أخيرة لتوحيد الإيقاع اللغوي عبر كل الفصول، (ج) تحويل الكتاب لنسخة PDF/EPUB منسّقة للنشر.
